# Zpracovani-dat-ETE
Doprovodné soubory k bakalářské práci 25 let monitorování životního prostředí v okolí ETE – využití GIS pro představení výsledků veřejnosti. 


## Použité knihovny
re (Regular expression) https://github.com/python/cpython/tree/3.14/Lib/re/
Path
numpy
pandas
scipy
geopandas
matplotlib
yaml
cdist
LogNorm

## Soubory
Soubor Zpracovani.ipynb obsahuje jupyter notebook s kodem ke zpracování dat. 
Soubor Body_lokace.xlsx obsahuje tabulku pro lokace měřicích bodů.
Soubor ETEDATA.xlsx obsahuje tabulku pro data z měření.
Soubor ArcGIS StoryMaps.pdf je archivovaný výtisk finální webové aplikace bez interaktivních prvků.
